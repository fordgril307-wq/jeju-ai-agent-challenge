# 에이전트 타깃 정리 (2026-11-17)

안마다 **에이전트를 직접 켜는 사람 한 명**으로 타깃 압축. 관광객·도민은 결과를 누리는 수혜자로 구분.

## 타깃을 정하는 기준
- 누가 직접 쓰나 — 한 직무
- 언제 쓰나 — 매주·매일 반복되는 순간
- 무엇을 결정하나
- 무엇을 받아 가나 — 바로 쓰는 완성물
- 지금은 어떻게 하나 — 에이전트가 덜어 줄 일

대회 조건이 'IT 비전문가 도민·공무원이 직접 쓰는 에이전트'라서 직접 사용자는 도민·공무원, 관광객은 수혜자로 설정.

## 2안-A 정리 — 밤길 안심 예보관

### 한 줄 정의
밤 생활인구·위험 지도·조명·CCTV·달력을 묶어 **읍면동별 7일 야간 안전 수요를 예보**하고, **순찰·조명 우선순위**와 관련 문서를 만들어 주는 에이전트

### 목표
- 도가 2026.8~9 발표한 치안 대책(어두운 길 조명·CCTV 확충, 야간 순찰 강화, CCTV 보관 연장)의 **'어디부터, 몇 시에'를 데이터로 결정**
- 금요일 순찰표 작성 → 질문 한 줄로 1분 안에 순찰 권고표·근거·보고서
- IT 비전문가 담당자가 센터 PC에서 직접 실행

### 직접 사용자를 자치경찰 순찰 계획 담당으로 둔 이유
- 매주 '다음 주 밤 순찰 구역·시간'을 정하는 반복 업무가 있는 한 사람 → 쓰는 순간이 분명
- 지금은 지난 신고 기록·현장 감각으로 결정 → 데이터 근거가 가장 필요한 자리
- 도 대책(순찰 강화·조명·CCTV)과 바로 연결돼 정책 활용 가능성이 선명

### 예측 대상 — '범죄'가 아닌 '안전 수요'
안전 수요 = **밤 인원 × 위험 가중 × 밝기·감시 부족 × 달력·날씨**
- 밤 인원: 21~03시 읍면동 생활인구 (센터 유동인구, 허브 유동인구 API)
- 위험 가중: 범죄주의구간·경찰서 권역 범죄 통계 (고정값)
- 밝기·감시 부족: 가로등·보안등·CCTV 밀도 (고정값)
- 달력·날씨: 주말·연휴 전날, 야간 행사, 비, 일몰 시각

### 에이전트 흐름
1. "다음 주 밤 순찰 어디부터?" 입력 → 지역·기간 되묻기
2. 밤 인원·관광 수요·날씨·행사·조명·CCTV 데이터 조회 (실패 시 저장본)
3. 읍면동 × 7일 안전 수요 예보 + 지난 4주 자기 검증
4. 1~3단계 등급 → 순찰 권고표 (구역·시간대·횟수, 자율방범대 협조)
5. 사각지대 후보 (조명·CCTV 보강, 보관 연장 우선구역)
6. 보고서·한·중·영 밤길 안내문 → 담당자 승인

### 받아 가는 것
순찰 권고표, 조명·CCTV 보강 후보, 범죄율 팩트체크 답변, 주간 보고서, 밤길 안내문

### 설계 원칙
개인 속성(국적·성별·연령) 점수 미사용 · 개별 사건 비추적 · 외부 공개는 '밝은 길 안내' 형태 · 보정 범죄율은 '공식 아님' 표기

### 수혜자
1인 관광객, 여성 야간 보행자 (야간 보행 두려움 여성 46.2% · 남성 14.4%, 2024), 심야 근무 도민

## 2안-B 정리 — 제주 안심 팩트체크

### 핵심 아이디어 (팀원 제안)
불안에 대한 답을 **공감 → 사실 판정 → 실제 노력** 3단 구조로 제공. 반박에서 끝나지 않고 걱정과 연결된 실제 조치까지 안내하는 점이 차별점.

### 직접 사용자를 소상공인으로 둔 이유
- 8월 이후 숙박업계에 안전 관련 문의·예약 변경 사례 보도 → 근거 있는 안내가 가장 필요한 사람
- 도민이 직접 쓰는 대회 조건과 부합
- 결과물(손님용 답장·안내문)이 분명해 시연 장면이 선명

### 에이전트 흐름
1. 손님 문의 입력 — 예: "실종 사고가 많아서 제주 가기 무서워요"
2. 문의 속 주장 분해 — '실종 사고가 많다'
3. 공식 통계 검색·계산 — 기준 시점·출처 함께
4. 판정 — 사실 / 일부 사실 / 사실 아님 / 확인 안 됨
5. 관련 실제 조치 검색 — 시행 중인 조치, 효과 수치 우선
6. 손님용 답장 작성 — 3단 구조, 한·중·영
7. 근거 카드 첨부 — 출처 링크·기준일

### 3단 답변에 쓸 수 있는 실제 조치 예시
- 2026.9 '제주 실종·위기사건 대응협의체' 구성, 통합 매뉴얼 수립(9/17)
- CCTV 집중관제와 AI 실종자 추적 플랫폼(TOSS) 수색 연계
- 어두운 길 조명·CCTV 확충, 야간 순찰 강화, CCTV 보관 기간 연장 추진

### 범위 (팀원 제안)
치안·실종 / 렌터카 사고 / 물가·바가지 / 항공 결항
