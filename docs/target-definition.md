# 에이전트 타깃 정리 (2026-11-17)

안마다 **에이전트를 직접 켜는 사람 한 명**으로 타깃 압축. 관광객·도민은 결과를 누리는 수혜자로 구분.

## 타깃을 정하는 기준
- 누가 직접 쓰나 — 한 직무
- 언제 쓰나 — 매주·매일 반복되는 순간
- 무엇을 결정하나
- 무엇을 받아 가나 — 바로 쓰는 완성물
- 지금은 어떻게 하나 — 에이전트가 덜어 줄 일

대회 조건이 'IT 비전문가 도민·공무원이 직접 쓰는 에이전트'라서 직접 사용자는 도민·공무원, 관광객은 수혜자로 설정.

## 2안-B 정리 — 제주 안심 팩트체크

### 핵심 아이디어 (팀원 제안)
불안에 대한 답을 **공감 → 사실 판정 → 실제 노력** 3단 구조로 제공. 반박에서 끝나지 않고 걱정과 연결된 실제 조치까지 안내하는 점이 차별점.

### 직접 사용자를 소상공인으로 둔 이유
- 8월 이후 숙박업계에 안전 관련 문의·예약 변경 사례 보도 → 근거 있는 안내가 가장 필요한 사람
- 도민이 직접 쓰는 대회 조건과 부합
- 결과물(손님용 답장·안내문)이 분명해 시연 장면이 선명

### 에이전트 흐름
1. 손님 문의 입력 — 예: "실종 사고가 많아서 제주 가기 무서워요"
2. 문의 속 주장 분해 — '실종 사고가 많다'
3. 공식 통계 검색·계산 — 기준 시점·출처 함께
4. 판정 — 사실 / 일부 사실 / 사실 아님 / 확인 안 됨
5. 관련 실제 조치 검색 — 시행 중인 조치, 효과 수치 우선
6. 손님용 답장 작성 — 3단 구조, 한·중·영
7. 근거 카드 첨부 — 출처 링크·기준일

### 3단 답변에 쓸 수 있는 실제 조치 예시
- 2026.9 '제주 실종·위기사건 대응협의체' 구성, 통합 매뉴얼 수립(9/17)
- CCTV 집중관제와 AI 실종자 추적 플랫폼(TOSS) 수색 연계
- 어두운 길 조명·CCTV 확충, 야간 순찰 강화, CCTV 보관 기간 연장 추진

### 범위 (팀원 제안)
치안·실종 / 렌터카 사고 / 물가·바가지 / 항공 결항
