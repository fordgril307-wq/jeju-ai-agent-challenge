## 4. 전처리 규칙

1. 날짜 통일: 모든 데이터 `YYYY-MM-DD`, 주 단위는 월요일 시작
2. 지역 통일: 행정동·법정동·배출지명 → **읍면동 코드** 매핑표 1개로 연결
3. 음식물 배출량: g → t 환산, 배출지·읍면동·일 합계 (태그 단위 저장 안 함)
4. 결측: 장비 오류 등 0값 연속 구간은 결측 처리 후 같은 요일 평균으로 보정, 보정 여부 표시
5. 이상치: 같은 요일 평균 ± 3 표준편차 밖 값은 표시 후 학습 제외
6. 외부 API: 호출 결과는 `data/cache/`에 날짜와 함께 저장, 실패 시 가장 최근 저장본 사용

## 7. 저장 구조

```
data/
  raw/        센터·허브·포털 원본 (공개 데이터 저장본, 센터 PC에서는 센터 원본 자동 사용, 저장소 미포함)
  center_agg/ 센터 PC 안 집계 결과 (센터에서만 생성) (지수·합계)
  cache/      외부 API 호출 저장본 (날짜별)
  ref/        읍면동 매핑표, 해외 연휴 표, 크루즈 일정, 클린하우스 위치
  derived/    전처리·파생 변수 결과
```
