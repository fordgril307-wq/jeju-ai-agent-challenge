## 4. 판정용 지표 정의

| 지표 | 정의 | 원천 |
|---|---|---|
| 인구 10만 명당 범죄 | 범죄 건수 ÷ 주민등록 인구 × 10만 (공식) | 사회지표 |
| 생활인구 보정 범죄율 | 범죄 건수 ÷ (주민 + 관광 체류 인구) × 10만 — '공식 아님' 표기 | 사회지표 + 방문자·유동인구 |
| 실종 신고 비중 | 제주 실종 신고 ÷ 전국 실종 신고 vs 제주 인구 ÷ 전국 인구 | 경찰 통계, 인구 통계 |
| 여행자 동향 | 최근 4주 방문 인구 ÷ 전년 같은 기간 | 센터 4-11 · 4-15, 관광공사 |
| 렌터카 사고율 | 렌터카 사고 ÷ 렌터카 등록 대수 (또는 추세만) | TAAS |
| 외식 단가 비교 | 제주 품목 평균가 ÷ 전국 평균가 | 참가격, 센터 포스 |
| 결항 현황 | 해당일 결항 편수 ÷ 전체 편수 | 공항공사 실시간 운항 |

## 5. 전처리·갱신 규칙

1. 모든 수치에 **기준 시점·출처** 필드 필수 — 없으면 답변에 사용 불가
2. 연 단위 통계는 최신 연도 + 직전 3년 추세 함께 저장
3. 센터 집계는 센터 안에서 비율·지수로만 산출, 10 미만 칸 자동 묶음
4. 실시간 API(운항·기상)는 호출 시점 표시, 실패 시 '확인 안 됨'
5. 조치 카드는 확인일 기준 30일 지나면 재확인 표시

```
  measures/   조치 카드 DB (measures.csv)
```

## 8. 사용하면서 쌓이는 데이터 (선순환)

앱을 쓰는 과정 자체가 새 데이터 자원 — 기능명세서 '데이터 선순환 구조' 참고

| 데이터 | 항목 | 수집 방법 | 활용 |
|---|---|---|---|
| 문의 주제 집계 | 날짜, 주제, 키워드, 언어, 건수 | 문의 입력 시 자동 분류 (원문 미저장) | 여행 불안 트렌드 |
| 답장 사용 기록 | 날짜, 주제, 사용 여부, 수정 여부, 수정 유형 | 답장 화면 자동 기록 | 템플릿 개선 |
| 손님 반응 (선택) | 날짜, 주제, 예약 유지/변경/취소 | 사장님 버튼 입력 | 효과적인 근거·카드 우선순위 |
| 데이터 공백 목록 | 날짜, 주장, 주제, '확인 안 됨' 사유 | 판정 시 자동 기록 | 공개 데이터 제안 근거 |
| 조치 카드 사용 기록 | 카드 ID, 노출·사용 횟수 | 자동 기록 | 카드 최신화 우선순위 |
