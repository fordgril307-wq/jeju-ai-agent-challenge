## 4. 전처리 규칙

1. 날짜 통일: 모든 데이터 `YYYY-MM-DD`, 밤은 당일 21시 ~ 다음 날 03시를 당일로 묶음, 주 단위는 월요일 시작
2. 지역 통일: 행정동·법정동·좌표 → **읍면동 코드** 매핑표 1개로 연결, 좌표 데이터는 읍면동 경계로 공간 결합
3. 시간대: 21~24시, 0~3시 두 구간
4. 결측: 유동인구 0값 연속 구간은 결측 처리 후 같은 요일 평균으로 보정, 보정 여부 표시
5. 고정 지도값(위험 가중·밝기·감시)은 기준일 함께 저장, 갱신 시 이전 버전 보관
6. 외부 API: 호출 결과는 `data/cache/`에 날짜와 함께 저장, 실패 시 가장 최근 저장본 사용

## 7. 저장 구조

```
data/
  raw/        센터·허브·포털 원본 (반출 가능분만, 저장소 미포함)
  center_agg/ 센터 반출 집계 결과 (밤 인원 지수)
  cache/      외부 API 호출 저장본 (날짜별)
  ref/        읍면동 매핑표·경계, 해외 연휴 표, 크루즈 일정, 근거 카드
  map/        위험 가중·밝기·감시 고정 지도값 (기준일별)
  derived/    전처리·파생 변수 결과
```
